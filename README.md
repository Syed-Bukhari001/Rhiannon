# Rhiannon Hikes Travel Prototype

Interactive Phase 1 prototype for a creator-led group travel website.

## Live Demo

After GitHub Pages finishes deploying, the prototype will be available at:

https://syed-bukhari001.github.io/Rhiannon/

## What Is Included

- Cinematic homepage with 3D scroll route experience
- Trips listing and trip detail page
- Mock deposit booking flow
- Admin dashboard mock for trips, bookings, travellers, messages and launch settings

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
